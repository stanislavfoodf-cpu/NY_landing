# Secret Kitchen — «В каждом окне свой Новый год»

Адаптивный интерактивный лендинг 2026/27 по макетам Figma и техническому заданию Secret Kitchen. Проект не имеет runtime-зависимостей: браузеру нужны только статические HTML, CSS, JavaScript, локальные шрифты и изображения.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска откройте `http://127.0.0.1:4173`.

Если установлен npm, доступны эквивалентные команды:

```bash
npm start
npm test
npm run build
npm run test:e2e
```

## Реализовано

- единый интерактивный фасад с 14 доступными с клавиатуры окнами;
- состояния `available`, `viewed` в пределах сессии и календарные `locked` в зоне `Europe/Moscow`;
- автоматическое открытие окон 6, 12, 13 и 14 по датам 20/28/31 декабря 2026 и 1 января 2027;
- истории в контексте затемнённого фасада с Escape, focus trap и возвратом фокуса;
- квиз из 5 вопросов, scoring R1–R8 и tie-break Q4 → Q1 → фиксированный приоритет;
- форма письма с валидацией и честным unavailable-состоянием до подключения backend;
- адаптивные центрированные модальные окна с внутренним скроллом;
- локальные шрифты FUD Grotesk, Source Sans Pro, Jost и Trebuchet MS;
- `prefers-reduced-motion`, видимый focus и отсутствие горизонтального overflow;
- события аналитики через `sk-ny:analytics` на `document`.

## Интеграции

Для production остаются внешние контракты:

- endpoint/CRM для хранения и отложенной отправки писем;
- согласованный текст и URL политики обработки данных;
- URL/deep link CTA «Собрать свой заказ»;
- ID Яндекс Метрики и финальные имена целей.

До появления этих данных форма не показывает фиктивный успех, а CTA заказа отмечен как недоступный.

## Проверки

- `tests/domain.test.mjs` — scoring, tie-break, календарная граница и валидация письма;
- `tests/build.mjs` — наличие обязательных локальных файлов;
- `tests/e2e.mjs` — Chrome-проверка ширин 375, 768, 1440 и 1920 px, исходной ширины 802 px, сценариев окна, locked-состояния, квиза и письма, console/network errors и overflow.

`test:e2e` использует установленный Google Chrome и путь к Playwright из Codex runtime; при запуске вне Codex замените импорт Playwright и `executablePath` на локальные.
