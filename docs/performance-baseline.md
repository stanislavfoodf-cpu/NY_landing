# Производительность лендинга

Исходная версия: коммит `cef81b1887f34355334a025f9866d59af758553e`. Измерение выполнено локально в Chrome с новым контекстом браузера для каждой ширины и пустым кэшем, без эмуляции плотности пикселей выше 1. Время локальной загрузки зависит от компьютера и не является прогнозом для пользователей.

| Ширина | Данные ресурсов до | Данные ресурсов после | Горизонтальное переполнение |
| --- | ---: | ---: | --- |
| 375 px | 47 539 860 байт | 16 139 823 байта | нет |
| 768 px | 47 539 860 байт | 16 139 823 байта | нет |
| 1440 px | 47 539 860 байт | 16 139 823 байта | нет |
| 1920 px | 47 539 860 байт | 16 139 823 байта | нет |

Объём измерен как сумма `encodedBodySize` записей Resource Timing на момент скрытия загрузчика; это размер тел ответов, без заголовков и HTML. После оптимизации сервер может сжимать текстовые ресурсы. При более высокой плотности пикселей выбираются более крупные изображения, поэтому объём отличается.

При дополнительной эмуляции сети 10 Мбит/с на загрузку, 5 Мбит/с на отправку и задержки 50 мс, ширине 393 px и DPR 1 исходная версия показала ошибку лоадера по тайм-ауту через 30,3 с; оптимизированная открылась за 13,1 с. Это единичные локальные замеры, а не гарантия времени загрузки в реальной сети.

Резервная копия исходного рабочего каталога и скриншоты четырёх ширин сохранены локально в папке `резервные копии/до-оптимизации-73mutDRT` рядом с каталогом проекта. Изображение здания V6 заменяет исходное намеренно; прежний лоадер, серверная проверка дат и поведение форм сохранены.
